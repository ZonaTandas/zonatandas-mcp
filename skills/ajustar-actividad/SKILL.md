# Ajustar una actividad

1. Localiza la actividad (`list_activities`, `get_activity`).
2. Enseña el antes y el después de lo que vas a cambiar.
3. `update_activity`. Si tiene reservas y cambian fechas, precio o plazas, avisa: se confirma con contraseña.
4. El cobro, la política de cancelación y el enlace a otra web no se cambian desde aquí: indica la pantalla del panel.
5. Da los enlaces de «Dónde verlo».
