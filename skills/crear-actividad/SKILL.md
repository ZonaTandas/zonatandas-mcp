# Crear una actividad

1. Pregunta lo que falte: circuito (`list_tracks`), fecha y horario, tipo y nombre. Si tiene plantillas (`list_templates`), ofrece partir de una.
2. `create_activity`. Nace **oculta**: no se vende todavía.
3. Enseña el enlace del panel que devuelve la respuesta para que la revise.
4. Publica sólo cuando lo pida (`publish_activity`): es delicada, avisa de que se abrirá el panel para confirmarla con su contraseña.
5. Tras publicar, da el enlace a la web.
