# Lo pendiente de hoy

1. `list_organizations`. Si hay varias, pregunta por cuál empezar o repasa todas.
2. `get_inbox` de cada una.
3. Cuenta primero lo que cuesta dinero o clientes (pagos por confirmar, cambios pedidos), después lo demás.
4. Para cada punto, di qué hacer y ofrece hacerlo. Confirmar una reserva cobra: es delicada, avisa antes.
5. Termina con los enlaces de «Dónde verlo» que traiga cada respuesta.
